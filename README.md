# KuroCat 二开功能

基于 [KuroCat](https://github.com/qianyiai/kurocat) 新增桌面快捷启动、AI 聊天、文件投喂、心情系统和大肥鱼动画。以下桌面互动功能适用于 Windows 10 / 11。

## 快捷启动

右键桌宠，打开「快捷启动」标签页。可以添加应用、文件夹和 Windows 快捷方式，最多 24 个。每个入口可自定义名称和图标，也可以调整顺序。

- 鼠标悬停在桌宠身上时展开快捷环。空间充足时最多显示三圈，各圈缓慢转动，鼠标移向图标时会停下来，方便点击。
- 靠近屏幕边缘时，快捷环会朝屏幕内侧展开。空间不足时可以分页。
- 开启全局快捷键后，前 8 项默认对应 `Alt+1` 到 `Alt+8`，每项也可以单独设置。
- 展开动画可选「能量轨道」「魔法阵 · 空间裂缝」和「漫画爆格」。

## AI 聊天

从桌宠右键菜单打开「AI 聊天」，填写兼容 Chat Completions 的服务地址、模型和 API 密钥。密钥保存在 Windows 凭据管理器。

可以输入消息和桌宠聊天。开启主动搭话后，桌宠会用气泡发起话题，可点击三个快捷回复之一，也可以自由输入。「试着搭话」可以立即预览。

## 文件投喂与暴食模式

右键桌宠，打开「文件投喂区」。这里有两种投喂方式。

- **拖到投喂区**。在桌面生成零食快捷方式，最多排队 12 份。桌宠饿了会走到图标旁，吃掉快捷方式后走回原位，原文件保留。可以点击「试喂一次」或「现在饿了」。
- **直接拖到桌宠身上**。原文件会立即移入 Windows 回收站，桌宠会原地吃掉。

**暴食模式**默认关闭，每次启动后都需要手动开启并确认风险。开启后，桌宠饿了会从它所在屏幕上可见的桌面普通文件中随机选一个，走到图标旁将文件移入回收站，吃完停在那里。文件夹、快捷方式和隐藏文件会跳过，重要文件也可能被选中。

## 心情与恶作剧

右键菜单的「心情」页显示心情值和状态。抚摸、投喂和聊天可以增加心情。连续 20 分钟没互动时，桌宠进入无聊状态，继续冷落会逐步扣分。

开启「允许恶作剧」后，桌宠会按心情决定什么时候捣乱。可以在同一页手动试玩「抖窗口」「拽窗口」和「踩跷跷板」。需要移动窗口时，目标是最上层的可见应用窗口，动作结束后会复位。想安静一会儿，可以点「暂时安静 1 小时」。

## 大肥鱼专属动画

- **端碗吃饭**。出发时端着碗，到位置后用筷子夹饭。
- **拽窗失手**。双手抓住窗框，身体后仰发力。窗口弹回时踉跄两下，用尾巴稳住。
- **踩窗弹跳**。蹲低起跳，落地屈身并甩尾，第二次落地会被弹高。
- **无聊打盹**。托腮打哈欠，脑袋一点一点垂下去。摸头会把它唤醒。

## 应用内更新

应用内检查更新使用 [Kcxuao/kurocat Releases](https://github.com/Kcxuao/kurocat/releases)。启动后会自动检查，也可以在右键菜单里手动检查。
